# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any NEXT BASKET repository, please report it responsibly.

**Email:** security@nextbasket.com
**Scope:** All repositories under this organization.

Please do NOT open a public GitHub issue for security vulnerabilities.

## Supported Versions

Only the latest release of each actively maintained project receives security updates.

## Response

We aim to acknowledge reports within 48 hours and provide a fix timeline within 7 days.
