# OS-NB

**Open Source & Platform Tools for NEXT BASKET**

Internal platform tooling, orchestration, infrastructure-as-code, and open-source projects supporting the [NEXT BASKET](https://nextbasket.com) e-commerce platform.

## About

OS-NB hosts the operational and platform engineering repositories for NEXT BASKET — a SaaS e-commerce platform enabling merchants to launch and manage online stores with AI-powered tools.
